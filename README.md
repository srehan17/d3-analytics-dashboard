# Portfolio Analytics Dashboard

An interactive data visualization project that transforms sample portfolio analytics data into a clean, responsive bar chart.

## Features

- Interactive D3.js bar chart
- CSV-based analytics data
- Hover tooltips showing new users and total users
- Responsive SVG layout
- Animated chart loading
- Clean dashboard-style UI

## Tech Stack

- HTML
- CSS
- JavaScript
- D3.js
- CSV data

## Data Note

This dashboard uses sample analytics data for demonstration purposes only.

## What I Learned

- How to load and parse CSV data with D3.js
- How to build responsive SVG charts
- How to create scales, axes, and tooltips
- How to improve chart readability with styling and animation
